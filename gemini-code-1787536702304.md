# Prompt / Instrucción de desarrollo: Entrega 1 - StayHub (Jakarta EE / WildFly)

## Contexto y Archivos del Entorno
Tenemos una carpeta de trabajo con los 3 archivos .zip provistos por la cátedra:
1. `java-1.8.0-openjdk-1.8.0.392-1.b08.redhat.windows.x86_64.zip`: JDK 8 estandarizado.
2. `wildfly-41.0.0.Final.zip`: Servidor de aplicaciones Jakarta EE.
3. `primer-componente.zip`: Esqueleto base / boilerplate en capas provisto por el profesor.

## Dominio Asignado
StayHub (Plataforma de gestión hotelera multi-proveedor).

## Objetivo del Primer Entregable
Implementar y desplegar en WildFly el primer componente del sistema: `ServicioDeHoteles` (Stateless), con arquitectura estricta en 3 capas:
- Capa de Presentación / Remota: Interfaces EJB (@Remote / @Local) con métodos `registrarHotel()`, `obtenerHotel()`, `listarHabitaciones()`, `validarHotelHabilitado()`.
- Capa de Negocio: EJB Stateless (@Stateless) con la lógica de validación de hoteles y políticas.
- Capa de Datos: DAO con modelo entidad/objeto para persistencia y desacoplamiento.

## Estructura de Carpetas a Configurar
/entorno-desarrollo/
│── /jdk8/               (Descomprimir java-1.8.0-openjdk...)
│── /wildfly/            (Descomprimir wildfly-41.0.0.Final)
└── /workspace/
    └── /stayhub-core/   (Descomprimir primer-componente.zip y renombrar/adaptar a StayHub)

## Paso a Paso a Ejecutar:
1. Configurar variables de entorno apuntando `JAVA_HOME` a `/jdk8` y agregando `/jdk8/bin` al `PATH`.
2. Probar el servidor ejecutando `/wildfly/bin/standalone.bat` (o `.sh`) y verificar acceso a `http://localhost:8080`.
3. Abrir el proyecto base (`primer-componente`) en el IDE (Eclipse / IntelliJ / NetBeans) y configurar el SDK en Java 8.
4. Crear el paquete base `com.stayhub.hoteles`:
   - `com.stayhub.hoteles.entities`: Entidad `Hotel` y `Habitacion`.
   - `com.stayhub.hoteles.dao`: Interface `IHotelDAO` e implementación `HotelDAOImpl` (en memoria o JPA).
   - `com.stayhub.hoteles.interfaces`: Interfaces `IConsultaHoteles` y `IGestionHoteles`.
   - `com.stayhub.hoteles.services`: EJB `@Stateless` `ServicioDeHotelesBean`.
   - `com.stayhub.client`: Cliente de prueba (Servlet o Standalone Client) para invocar el EJB y verificar funcionamiento.
5. Empaquetar el artefacto (.war o .ear) mediante Maven/Gradle (`mvn clean package`) y desplegar en `/wildfly/standalone/deployments/`.
6. Verificar en consola de WildFly el binding JNDI del EJB y su correcta ejecución.
